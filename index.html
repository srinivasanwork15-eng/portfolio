About Me

Crafting Web Experiences with Care

Hello! My name is Alex, and I am an enthusiastic frontend developer based in California. My passion for web development began when I created my first interactive web page and saw how code instantly transforms into visual, interactive reality.

I specialize in writing clean, well-structured HTML5, responsive and modern CSS3 layouts (Flexbox & CSS Grid), and interactive Vanilla JavaScript. I value simplicity, accessibility, performance, and user-centric design.

When I'm not writing code, you can find me exploring modern UI/UX design trends, contributing to open-source learning communities, reading technology articles, or experimenting with new browser APIs.
